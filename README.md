# Wedding Quest V67 — Cuộn lịch vàng kim 3D

Thay hai thiệp sự kiện bằng cuộn lịch có trục vàng kim trên và dưới. Khi cuộn tới, giấy cuộn từ trên xuống trong khoảng 3,3 giây và nội dung xuất hiện. Có nút xem lại animation.

Chỉnh ngày giờ, tên địa điểm, địa chỉ và liên kết bản đồ tại `config.js`, các mục `ceremonyDate`, `weddingDate`, `ceremony`, `reception`.

Đăng GitHub Pages: giải nén, vào thư mục `Wedding-Quest-v67-source`, tải **nội dung bên trong thư mục này** lên cấp gốc repository. Các file `index.html`, `config.js`, `app.js`, `style.css`, `v16.js` và `assets` phải nằm cạnh nhau.
